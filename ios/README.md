# JM Invest for iPhone

아이폰에서 키움 미국주식 실시간 호가와 체결가를 직접 수신하고, 사용자가 확인한 매수·매도 주문을 키움에 전송하는 개인용 앱입니다. 앱을 사용하는 동안 Mac이나 ngrok이 필요하지 않습니다.

## 설치와 첫 연결

1. Xcode 15 이상에서 `ios/JMInvest.xcodeproj`를 열고, **JMInvest → Signing & Capabilities → Team**에서 본인 계정을 선택합니다. 번들 ID를 등록할 수 없다는 메시지가 나오면 본인 계정의 고유 ID를 입력합니다.
2. iOS 17 이상인 아이폰을 연결해 기기를 신뢰하고, 필요하면 아이폰 **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켭니다. Xcode에서 기기를 선택하고 **Run**을 누릅니다. 무료 Personal Team으로 설치한 앱은 프로비저닝이 7일 후 만료되어 다시 빌드·설치해야 합니다. [Apple 계정 안내](https://developer.apple.com/help/account/basics/about-your-developer-account)
3. 키움 REST API의 **계좌 App Key 관리**에 아이폰이 인터넷에 나갈 때 사용하는 공인 IP를 등록합니다. 집 Wi-Fi라면 집 공인 IP를 등록합니다. 외출 중 같은 IP를 쓰려면 집 공유기의 VPN 서버에 연결하고, 키움 HTTPS와 WebSocket 트래픽이 집 회선을 거치도록 설정합니다. 외부에서 접속 가능한 집 회선과 VPN 서버 지원 공유기가 있으면 무료 WireGuard iOS 앱을 사용할 수 있습니다. 집 공인 IP가 바뀌면 키움에도 새 주소를 등록합니다. [키움 이용 안내](https://openapi.kiwoom.com/intro/serviceInfo) · [WireGuard](https://www.wireguard.com/install/)
4. 아이폰에서 **API 키 연결**을 누르고 본인의 실계좌 App Key와 App Secret을 입력합니다. 앱은 키움에서 인증이 성공한 뒤 기기 잠금 해제 시에만 접근 가능한 Keychain에 키를 저장합니다.
5. 종목 티커를 입력해 **조회**합니다. **최근 조회 호가**는 REST 스냅샷이며, 키움에서 WebSocket 호가를 수신하면 **실시간 호가**로 바뀝니다. 배경으로 전환하면 스트림을 종료하고, 다시 열면 종목과 잔고를 조회하고 재연결합니다.

## 외출 전 VPN 확인

1. 집 Wi-Fi에서 키움의 **계좌 App Key 관리 → 현재 나의 IP**와 등록 IP가 같은지 확인합니다.
2. 집 공유기의 WireGuard 서버에서 아이폰용 프로필을 만들어 아이폰 WireGuard 앱으로 가져옵니다. 공유기에서 **인터넷 트래픽도 VPN 사용** 또는 **전체 터널**을 선택합니다. 집 내부 기기에만 접속하는 설정에서는 키움 요청이 이동통신 회선으로 나갑니다.
3. 아이폰 Wi-Fi를 끄고 셀룰러에서 VPN을 켭니다. 키움 페이지에서 현재 IP가 등록한 집 IP와 같은지 확인한 다음 JM Invest 앱을 열어 종목 호가를 조회합니다.

## 주문

**Buy / Sell → 주문 종류 → 수량·지정가 → 주문 확인** 순서입니다. 가격을 눌러 지정가를 입력할 수 있습니다. 실전 주문 화면에서 종목·거래소·방향·수량·가격을 확인하고 **주문하기**를 누른 후 기기 인증을 완료하면 접수를 요청합니다. 시장가 계열의 실제 체결 금액은 체결 후 결정됩니다.

키움 주문번호가 표시되면 접수된 상태입니다. 전송 중 연결이 끊겨 결과가 불확실하면 키움 주문내역을 확인하세요. 이 경우 앱은 재전송하지 않으며 앱을 다시 열어도 확인할 주문 정보를 보관합니다.

아이폰 Safari의 JM Invest 종목 주문창에서는 **iPhone 앱에서 열기**로 티커와 매수·매도 방향을 넘길 수 있습니다. 수량과 가격은 앱 안에서 입력합니다. 설치 직후에는 아이폰 홈 화면에서 앱을 직접 열어도 됩니다.

## 검증

`ios/test.sh`는 macOS에서 모의 REST 응답과 FT/FE 메시지로 호가 파싱, 거래소·보유수량 확인, 주문 가격 정밀도, 중복 전송 방지와 불확실한 응답을 검사합니다. 실제 계좌 정보는 사용하지 않습니다. 저장소의 **iPhone build and trading checks** 워크플로는 시뮬레이터 대상 빌드도 수행합니다.
